# 🛡️ FraudShield

AI-powered fraud detection platform for analyzing transactions and identifying potentially fraudulent activities.

## 🚀 Features

- 🔍 Fraud transaction prediction
- 📊 Analytics dashboard
- 📁 Transaction data upload
- 📈 Fraud statistics & visualization
- 👨‍💼 Admin dashboard
- ⚡ FastAPI + Next.js
- ☁️ Vercel + Render deployment

## 🛠️ Tech Stack

**Frontend:** Next.js, TypeScript, Tailwind CSS, Recharts  
**Backend:** FastAPI, Python, Pandas, Scikit-learn  
**Deployment:** Vercel + Render

## 🌐 Live Demo

**Backend:** https://fraudshield-cvly.onrender.com
